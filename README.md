# Banking-Customer-Analysis
Banking Customer Analysis is an end-to-end data analytics project focused on understanding customer financial behavior, banking product usage, and business trends using customer banking data. The primary objective of this project is to analyze customer financial patterns, uncover actionable business insights, and support data-driven decision-making in the banking domain.

This project was developed using Python, SQL, Power BI, and data visualization techniques to perform comprehensive exploratory data analysis (EDA) and dashboard reporting. Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn were used for data cleaning, preprocessing, analysis, and visualization, while SQL was used for querying structured data and generating business insights. Power BI was used to build interactive dashboards and KPI reports for better decision-making.

The analysis began with data preprocessing, where missing values were handled, duplicate records were checked, and categorical and numerical features were prepared for analysis. Feature engineering techniques were applied to create meaningful business metrics such as total loan exposure and total deposit balances by combining multiple financial attributes.

Exploratory data analysis was conducted to understand customer demographics, financial product adoption, income distribution, deposit behavior, loan exposure, credit card usage, risk classification, loyalty segmentation, fee structure preferences, and banking account balances. Both univariate and bivariate analysis were performed to identify trends and relationships across customer groups.

Key insights from the analysis revealed that the customer base is primarily composed of medium-income individuals with balanced gender representation and a higher concentration of European customers. Most customers maintain only one credit card, moderate savings balances, and lower credit card liabilities. Strong positive relationships were observed between bank deposits, checking accounts, and savings accounts, indicating consistent financial behavior across deposit products.

SQL analysis was used to perform aggregation, filtering, grouping, and conditional queries to answer business-focused questions related to customer segmentation, deposit trends, loan behavior, and financial performance. Interactive Power BI dashboards were developed to visualize KPIs such as total loans, total deposits, customer segmentation, financial product usage, and risk distribution.

This project demonstrates practical data analyst skills including data cleaning, exploratory data analysis, SQL querying, data visualization, KPI reporting, business problem-solving, and dashboard development. It serves as a strong portfolio project for showcasing analytical thinking, business insight generation, and end-to-end data analysis capabilities in the banking domain.

Future improvements for this project may include customer churn analysis, predictive analytics for loan risk assessment, customer lifetime value analysis, and advanced dashboard automation for real-time reporting.

Technologies Used: Python, Pandas, NumPy, Matplotlib, Seaborn, SQL, Power BI, Jupyter Notebook
